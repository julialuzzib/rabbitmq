# RabbitMQ
Mensageria e Fila de Mensagens: Teste de um sistema para gerenciar os pedidos de um restaurante.

## No terminal bash:
```
npm install

docker-compose up -d

npm start

npm run cozinha
npm run financeiro

```

### Acessar:
http://localhost:3000 - Restaurante, envio de pedidos. 

http://localhost:15672 - Painel web do RabbitMQ.
